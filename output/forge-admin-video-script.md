# Forge Admin 宣传视频文案草稿

低代码最怕什么？不是搭不出来，而是上线以后不能维护、不能扩展，更交付不了源码。Forge Admin 这次升级，就是要解决这个问题。

首先看应用概览。Forge Admin 现在真正以应用为中心：左侧按业务域筛选，右侧用紧凑卡片呈现设计状态、更新时间，以及对象、入口、流程、扩展数量。进入应用、发布、代码预览与下载，都能直接操作。

进入应用，就是独立开发工作台。应用就绪度、最近变更和待办问题一目了然；数据对象、页面、自动化、扩展、权限和发布历史集中管理。物理表、字段、数据源和同步状态也直接可见，让业务设计与数据库始终对得上。

单表、主子表、左树右表共享同一套低代码协议。表单、列表、详情、按钮和触发器协同工作；草稿随时预览，发布形成独立版本，变更可追踪、可恢复。

更关键的是，Forge Admin 交付的不是运行时黑盒。前端复用统一解释器，后端生成标准的 Controller、Service、Mapper 和 Mapper XML。源码可预览、可下载，也能继续修改复杂查询和业务逻辑；再次生成时，自定义扩展不会被覆盖。

编码规则也升级成分段式配置。日期、固定值、流水号、业务变量和系统变量自由组合；流水号支持多种进制和周期重置，还能按仓库、组织独立计数，预览不消耗真实序号。最新优化中，易混淆字符 I、O、Z 可以逐个排除；低代码自动编号也共用这套引擎。

再加上 Flowable 工作流、RBAC 权限、多租户隔离、数据权限和 API 加解密，Forge Admin 把低代码效率与标准工程能力放进了同一套平台。如果你既想搭得快，又希望系统改得动、交得出、管得住，欢迎体验 Forge Admin。开源地址和在线演示就在视频简介。
